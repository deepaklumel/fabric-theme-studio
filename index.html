Export theme

Copy the theme JSON, share a link to it, or download it as a .json file.

Apply in Fabric Planning

  1. Select Copy JSON or Download.
  2. In Fabric Planning, on the Home tab, select Themes.
  3. At the bottom of the Themes pane, select Import.
  4. Paste the JSON or upload the file to create the theme.
